КАК ДА ДОБАВЯШ СНИМКИ В ГАЛЕРИЯТА
==================================

1) Пусни файла на снимката в тази папка (gallery/).
   Препоръчително: компресирай снимката до ~150-400 KB
   (напр. с https://squoosh.app или TinyPNG), за да зарежда бързо сайтът.

2) Отвори gallery.html с текстов редактор и намери реда:

   const IMAGES = [

3) Добави нов ред за снимката, по следния образец:

   { src: "gallery/имена-на-файла.jpg", alt: "Кратко описание" },

   Пример:
   { src: "gallery/repatrak-1.jpg", alt: "Репатрак Valcron Assistance" },

4) Запази файла — снимката ще се появи автоматично в решетката на
   страница "Галерия", в реда, в който си я добавил.

Оптимален брой снимки: 9–15 за старт е достатъчно за пълноценна
галерия, но можеш да добавяш без ограничение — решетката се
пренарежда автоматично.
